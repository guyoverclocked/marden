# Marden 2.0.1 — Highlight and sync update

## Fixed

- Highlight selected reader text on desktop and native builds
- Save highlights as portable `==Markdown highlights==`, so they sync with the document on every signed-in device
- Open Google sign-in in the system browser on desktop and return safely to Marden
- Confirmed sign-out is available from Profile and retains the on-device library

## v2.0.0 — Your library, on your devices

Marden 2 adds optional account-backed sync, portable library backups, direct Markdown file opening, and Windows desktop builds.

## What’s new

- Optional Google sign-in and private, account-scoped cloud sync
- Safe conflict copies when an offline edit collides with a newer cloud version
- Export and merge a portable Marden backup
- Open Markdown files directly from Android, iOS, and macOS; share files into Marden from Android and iOS
- Updated Markdown rendering and reader interactions
- macOS Universal and Windows installer builds
- GitHub Release updates for Android sideloads and desktop installations

## Install

- **Android:** download the v2 APK, open it, and approve installation from the browser or file manager if Android asks.
- **macOS:** download the DMG for your Mac, drag Marden to Applications, then right-click Marden and choose **Open** the first time if it is not notarized.
- **Windows:** download the v2 installer and complete the setup wizard.

Marden remains local-first: an account is optional, and cloud sync is only used after sign-in.
